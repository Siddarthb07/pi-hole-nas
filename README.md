# pi-hole-nas

DietPi and Raspberry Pi OS overlay for a home **Pi-hole DNS sinkhole** plus **Samba NAS** on a Raspberry Pi — per-PC ad blocking (router DNS unchanged), shared `\\rpi\share`, and optional LCD stats / wake orchestration helpers.

**Start here:** [SETUP.md](./SETUP.md) — flash SD, run `apply-overlay.ps1`, first boot, `set-pc-dns.ps1`, and Samba mapping.
